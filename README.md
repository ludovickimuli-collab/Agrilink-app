# Agrilink

Agrilink is a simple Android smart-farming and agricultural e-commerce prototype.

## Included in this build
- Branded Agrilink home screen using the supplied logo
- Farm marketplace with search
- Product cards and local cart
- Sell/publish product screen
- Checkout and local order history
- Profile shortcuts
- AI diagnosis placeholder ready for future backend/API integration
- GitHub Actions debug APK build and artifact upload

This version is intentionally local/offline: products, cart and orders live in memory while the app is open. A backend such as Firebase or a REST API can be connected later for real accounts, payments, inventory and farmer/customer synchronization.
